# AI Procurement Bid Compliance Platform

This repository contains the Next.js application for the AI Procurement Bid Compliance Platform.

## Getting Started

1. Clone the repository.
2. Install dependencies: `npm install`
3. Copy `.env.example` to `.env.local` and populate variables.
4. Run the development server: `npm run dev`

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Development Phases

This project is built iteratively following a phased approach:

- PHASE 0: Project Rules & Planning (Completed)
- PHASE 1: Application Foundation
- PHASE 2: Supabase Database & Security
- PHASE 3: Authentication & User System
- PHASE 4: Main UI & Dashboard
- PHASE 5: Tender Management
- PHASE 6: Document Management
- PHASE 7: AI Requirement Extraction
- PHASE 8: Bidder Intelligence & Extraction
- PHASE 9: Compliance & Verification Engine
- PHASE 10: Officer Review & Evidence
- PHASE 11: Reports & Audit System
- PHASE 12: Testing, Security & Deployment
